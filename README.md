# Brioche · landing

`index.html` es un archivo único y autocontenido: fotos, fuentes y código van dentro. Súbelo a la raíz del repositorio y activa GitHub Pages (Settings → Pages → rama main, carpeta /root).

Antes de publicar, en el archivo editable:
- Poner el número de WhatsApp de Brioche (Tweaks → Contacto).
- Dirección y horario (Tweaks → Local).
- Precios de Truffle Burger y Pulled Pork Fries.
